Publish today's paper

Paste the day's questions, set a code, and this checks the paper and (optionally) encrypts it so the answers are not readable in your public repo. Nothing is uploaded anywhere.

Give this to the students on the morning of the test. It is also the encryption key.

Daily checklist

  • 1Copy tomorrow's questions out of question-bank/ into the box above.
  • 2Press Check the paper and fix anything it flags.
  • 3Press Encrypt & download, then replace data/questions.json with the downloaded file.
  • 4Press Hash the code and paste the hash into data/access.json as dayCodeHash, clearing dayCode.
  • 5Commit, push, then send the code to the students.

Keep this page out of the students' hands — it is only a convenience, not a secret.
